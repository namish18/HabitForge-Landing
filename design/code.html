01 / ARCHITECTURAL SHIFT

Not another database-backed productivity app.

Your productivity history lives where your code lives. Structured application data is stored as plain JSON files and updated natively through GitHub's authenticated API.

lock

Private by architecture

Your application data is stored inside your own private repository rather than a multi-tenant shared database. No third-party analytics scripts reading your daily logs.

SCOPE: repo (private write)
history

Version controlled

Every successful modification becomes an atomic Git commit with cryptographic SHA verification. Enjoy instant rollbacks, git diffs, and branch-level isolation for task changes.

HISTORY: Immutable DAG ledger
cloud_off

Simple infrastructure

Skip dedicated Postgres hosting, ORM migrations, vacuum jobs, and vendor lock-in. HabitForge Lite harnesses GitHub's battle-tested infrastructure as a serverless back end.

05 / PERSISTENCE ARCHITECTURE

Your database is a repository.

A deliberate architectural design choice for developers who demand complete sovereignty and total auditability.

THE LEGACY PARADIGM

Multi-tenant Cloud Database

Your data sits beside millions of other records in an opaque, managed database cluster.

Data Isolation Logical row isolation (Risk)
Backup Access CSV / JSON export dump
Audit & Rollback Opaque system logs
Vendor Risk Lock-in & pricing tiers
Result: You lease access to your own daily memory.
THE HABITFORGE MODEL SOVEREIGN

Private Git Repository

Your productivity records are native Git commits, completely isolated inside your private GitHub account.

Data Isolation Physical Git repo isolation
Backup Access git clone && rsync
Audit & Rollback git log / git revert
Vendor Risk Zero. Open-source core.
Result: Complete sovereignty, perpetual local ownership.
